# CheckPoint 3 — CPAD

Aplicativo mobile desenvolvido em React Native com Expo para consultar séries de televisão e seus episódios utilizando a API pública TVmaze.

## Funcionalidades

- Listagem de séries de televisão.
- Exibição das imagens e dos nomes das séries.
- Navegação para a tela de episódios de uma série.
- Consulta dos episódios por meio do identificador da série.
- Indicador de carregamento e tratamento de erros durante as requisições.
- Tratamento de séries sem imagem disponível.

## Tecnologias utilizadas

- React Native
- Expo
- JavaScript
- React Navigation
- API TVmaze

## API utilizada

- Lista de séries: https://api.tvmaze.com/shows
- Episódios de uma série: https://api.tvmaze.com/shows/{id}/episodes

## Como executar o projeto

1. Instale o Node.js e o npm.
2. Clone este repositório.
3. Abra a pasta do projeto no terminal.
4. Instale as dependências:

   '''bash
   npm install
   '''

5. Inicie o projeto:

   '''bash
n   npx expo start
   '''

6. Siga as instruções exibidas no terminal para executar o aplicativo no ambiente disponível.
